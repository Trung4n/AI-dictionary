# Report (Springer LNCS)

```
paper/
  main.tex            title, authors, \input of every section, bibliography
  sections/           one file per section, in the order the spec requires
  tables/             generated by make_assets.py (do not edit by hand)
  figures/            generated by make_assets.py
  references.bib
  make_assets.py      every table and figure, from reports/
```

## Rebuild tables and figures

```bash
python paper/make_assets.py
# with the processed dataset in dataset/ and the saved validation predictions
# (Kaggle output of AI_pictionary version 8: runs/predictions_all/<run>.npz):
python paper/make_assets.py --val-predictions <folder of <run>.npz>
```

The first command needs only `numpy` and `matplotlib` and writes 7 tables and 4 figures.
The second also draws `fig_prefix_example.pdf` (one validation drawing, three inputs) and
`fig_qualitative.pdf` (successes and failures of the CNN at epsilon = 5%). Both use validation
data only; the test split is never opened. Until they exist, the report compiles without the
first and with a placeholder box for the second.

## Compile on Prism

1. Create the project from the official Springer LNCS template, which provides `llncs.cls`
   and `splncs04.bst`. Do not change margins or font sizes.
2. Replace the template's main file with `main.tex`, and upload `sections/`, `tables/`,
   `figures/` and `references.bib` with the same folder names.
3. Compile with pdfLaTeX and BibTeX.
